# Project history (curated)

This repository was originally prototyped as a broad “framework” workspace.
It has been refactored into a **trilogy‑aligned reproducibility toolkit** for the Noetiko Convergence papers.

Key changes in the refactor:

- Removed application‑layer / product scaffolding from the default research path.
- Replaced speculative narrative claims with **operational definitions**, **quality gates**, **surrogates**, and **nulls**.
- Added a minimal proof‑of‑protocol demo and unit‑test coverage for core metrics.

If you still need legacy application prototypes (e.g., dashboard, API glue), keep them in a separate repository or a clearly labeled `legacy/` folder.
